# deepseek_project

加密货币（币圈）套利交易系统。

## 目标

构建一套可持续运行的加密资产套利系统：自动发现价差、评估手续费与滑点、执行下单并记录盈亏。

## 技术选型原则

**不重复造轮子，优先复用成熟开源项目。**

| 层 | 选型 | 理由 |
|---|---|---|
| 交易所接入 | [`ccxt`](https://github.com/ccxt/ccxt) | 统一封装 100+ 交易所的行情、下单、账户接口，无需自己对接每家 API |
| 数据处理 | `pandas` / `numpy` | 价差矩阵、时序对齐、统计计算 |
| 回测/框架参考 | `freqtrade`、`hummingbot`、`jesse` | 可按需借鉴或改造，不从头写撮合与风控 |
| 定时/守护 | 待定 | 运行调度与进程保活 |

## 套利类型（待确定）

三种主流方向，技术复杂度与资金要求差异很大，需先选型再动手：

1. **跨所价差套利** —— 同一币种在不同交易所的现货价差
2. **期现套利** —— 现货与永续合约之间的资金费率差
3. **三角套利** —— 单一交易所内三个币种构成闭环

> 当前状态：选型中。确定后在此处补充具体方案。

## 目录结构（规划）

```
.
├── src/                # 核心代码
│   ├── exchanges/      # ccxt 交易所封装与统一接口
│   ├── strategy/       # 套利策略（价差发现、信号生成）
│   ├── execution/      # 下单、撤单、仓位与风控
│   └── monitor/        # 行情采集、日志、告警
├── config/             # 配置（不含密钥）
├── scripts/            # 运维脚本
├── tests/              # 测试
└── docs/               # 设计与决策记录
```

## 快速开始

```bash
# 1. 准备环境（Python 3.11+）
python -m venv .venv
.venv\Scripts\activate

# 2. 安装依赖
pip install ccxt pandas numpy

# 3. 配置密钥
cp .env.example .env   # 填入自己的交易所 API Key
```

## 安全约定

- **密钥绝不入库**：`.env` 已被 `.gitignore` 排除，仓库只保留 `.env.example` 模板。
- 交易所 API Key 只授予**交易权限**，不授予提现权限。
- 默认以**模拟盘 / dry-run** 模式启动，确认策略逻辑后再接实盘。
- 涉及真实资金的代码路径，先写测试再上线。

## 风险提示

套利并非无风险：存在滑点、手续费侵蚀、转账延迟、交易所限额与提币暂停等风险。本项目代码按现状提供，不构成投资建议，使用风险自担。
